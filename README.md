# 知乎收藏 · 个人知识库

当前推荐方案是 **一个站点、两个页面**：先用各自的知乎账号授权，再进入按知乎稳定用户 ID 隔离的知识库。复用原来的图谱与阅读界面，但不把作者的本地笔记库开放给访客。

| 入口 | 用途 | 数据边界 |
| --- | --- | --- |
| [8100 账号入口](http://127.0.0.1:8100/) | 绑定账号、查看公开收藏夹、按页收录摘要 | 当前授权账号的公开收藏 |
| [8100 个人工作区](http://127.0.0.1:8100/workspace/) | 图谱、搜索、摘要阅读；未登录先到带 returnTo 的登录页 | 服务端按稳定用户 ID 隔离 |
| [8099 作者本地版](http://127.0.0.1:8099/) | 原有全文、分节和 MOC 演示 | 作者共享文件库，仅本机使用，不向不同访客公开 |

**真实双账号授权仍为 0 / 2。** 代码与模拟验证已完成，但应用凭证、登记回调和平台权限仍须实际联调。登录知乎网页不等于已经授权给这个应用。


打开 [8100 统一入口](http://127.0.0.1:8100/)。默认仅监听本机；未配置时授权按钮禁用，不伪装为已绑定，不提供模拟账号。已有进程占用端口时不要重复启动。

实际授权请先停止当前未配置的预览进程，再运行[安全启动脚本](D:/项目ai/知乎/工具/启动OAuth验证.ps1)：

### 访问流程

1. 未登录访问个人工作区会先到 **/login?returnTo=...**；也可从账号页点击知乎授权，由用户本人确认账号并同意授权。
2. 平台回到同站的 **/auth/zhihu/callback**；后端校验 state、兑换 Token、读取官方 /user 的 uid 与 fullname。
3. 成功后回到经过校验的 **returnTo**，默认 **/workspace/**。首次使用为空库，可通过“账号 / 收藏”回账号页选择收藏夹、点击“收录最近一页摘要”。
4. 回到个人工作区查看图谱、搜索与摘要；同一账号重新授权仍可看到已保存的摘要。

这两个页面由同一个 Python 服务提供，**不需要再跳到 8099，也不需要两个对外站点**。本实现要求入口与回调同源，不能把 8100 的会话直接拿到 8099 使用。

### returnTo 登录回跳

已按参考站的方式补齐“访问目标 → 登录 → 回到目标”，并保留普通 query、hash 和原有编码；刷新登录页、取消后重试、工作区退出 / 到期都不会丢掉安全目标。

| 实际启动的入口 | 登录示例 | 默认回到哪里 |
| --- | --- | --- |
| OAuth验证服务.py，推荐多人使用 | [8100 登录](http://127.0.0.1:8100/login?returnTo=%2Fworkspace%2F) | /workspace/，按稳定 UID 隔离 |
| 应用.py，历史单租户入口 | [8099 一体化登录](http://127.0.0.1:8099/login?returnTo=%2F) | /，仍是共享作者库，不用于多人发布 |

已登录访问 /login 会直接回跳。外站地址、登录循环、接口 / 资源路径、重复 returnTo 等会回落到该入口默认目标；目标绑定服务端的一次性 state，不能靠篡改回调参数改变它。

**returnTo 是站内页面位置，不是登记给知乎的回调地址。** 平台回调仍固定为同源的 /auth/zhihu/callback。以上两种入口二选一，不跨端口传递会话；单独运行 服务.py 的纯本地 8099 没有这套登录入口。

本轮没有强制重启现有 8100 / 8099，也没有部署公网；**重启实际使用的对应服务后新代码才生效**。先准备好在本机安全输入凭证，重启会清除内存中的 Token 和会话。复测范围见 [returnTo 回跳验收](D:/项目ai/知乎/outputs/returnTo回跳验收-2026-09-13.md)。

### 当前功能边界

- 只读取官方允许的**公开收藏夹**，列表最多 50 个，列表接口未提供分页，不保证已列出全部。
- 内容每页 20 条，手动使用 NextOffset 加载；只保存最近成功读取的一页，重复收录更新原条目，不批量遍历账号。
- 收录的是标题、摘要、来源及必要元数据，**不是全文，也未调用大模型拆分**。图谱连接表示摘要所属收藏夹，不是语义推断关系。
- 索引、笔记、图谱、搜索和写入均按服务端识别的稳定用户 ID 限定；不接受浏览器指定别人的用户 ID。
- Token 仅在服务端内存；退出、过期或重启后需重新授权。已收录摘要独立持久保存，退出不会删除。
- 默认每个用户最多 2,000 条摘要。当前为单实例、单进程演示；不支持多 worker 或无状态多副本部署。


默认只扫描旧式收藏夹目录和 `.raw/inbox`，不扫描已归档的 `.raw/sources`。原文正文哈希匹配、分析缓存有效且 MOC 存在时直接跳过。无缓存时，配置了模型才可能调用远端；无配置或调用失败时使用本地规则。

| 选项 | 实际作用 |
| --- | --- |
| `--包含归档` | 将 `.raw/sources` 加入候选范围；本身不强制重建。 |
| `--强制` | 候选文章即使未变化也重建生成目录；仍复用有效分析缓存。 |
| `--重新分析` | 忽略分析缓存；有模型配置时可能再次调用远端。 |
| `--本地` | 不调用远端模型；没有可用缓存时用本地规则，可能得到不同分节。 |
| `--限制 N` | 最多成功处理 N 篇，0 表示不限制。 |

**重建会替换文章生成目录，请先备份，避免覆盖手工修改。** 重建归档文章需要显式加 `--包含归档`；只做日常刷新不需要以上强制选项。

支持 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL`、`OPENAI_TIMEOUT_MS`、`OPENAI_MAX_ATTEMPTS`。输出经 schema 校验、标签清理、长度限制和敏感信息脱敏。现有 6 篇文章保留 `processing: codex-offline` 的离线分析结果和缓存，本轮收尾未重新分析。

- 网页左下角「重新扫描笔记库」：依次执行 `知识重构.py`、`处理.py`，成功后重载索引、图谱与当前笔记 / 标签视图，并保留图谱坐标和手动缩放视点；**不执行抓取**。有新增候选且配置了模型时可能调用远端分析；当前候选为 0，不会调用模型。重扫互斥，重复请求返回 409。

## 作者本地版：网页功能

### 以图谱为中心的工作区

- **默认全幅图谱**：窄工具栏、左侧「收藏夹 → 文章 → 分节」文件树、顶部视图标签，不再使用卡片首页或图谱弹窗。
- **每个节点都可单击打开**：文章 → MOC 总览；分节 → 对应正文；概念 → 概念笔记；标签 → 按文章分组的关联分节。有概念页的标签额外提供概念笔记入口，没有概念页的标签也可正常浏览。
- **图谱 + 阅读分栏**：打开节点不离开图谱；阅读区可展开，关闭按钮、图谱标签或 Escape 可回到全幅图谱。元信息、大纲、相关笔记和反链收在阅读区的详情按钮中。
- **浏览操作**：单击打开，拖动节点整理布局，拖动空白平移，滚轮或 ± 缩放，Home / 适应按钮显示全部节点。悬停显示完整名称和关联数量。
- **键盘与节点查找**：右上角可搜索全部节点；图谱聚焦后方向键选择、Enter 打开。标签与笔记均支持地址 hash 深链接及浏览器前进 / 后退。
- **稳定布局**：调整窗口或分栏宽度不重新随机排图；布局冷却后停止动画，页面隐藏或阅读展开时暂停主图绘制。
- **窄屏适配**：小屏改为图谱在上、阅读在下；文件树可通过左上按钮开关。支持明暗主题。

保留 MOC 阅读线、上一节 / 返回总览 / 下一节、跨文章双链及图片 / 表格 / 公式。搜索打开分节会展开文件树祖先目录。

搜索支持标题、作者、标签和正文；`#RAG` 为精确标签查询，包含匹配分节，不等同于全文关键词 `RAG`。连续搜索或切换笔记时不会被过期请求覆盖；关闭搜索会取消未完成请求。

笔记与图片接口限制在 `wiki` 内；原文、分析缓存、目录穿越与越界链接不作为可读笔记暴露。图片带类型保护与隔离策略。此服务面向本机使用，不建议直接暴露到公网。
